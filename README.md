# BALLER PATH · PROOF INSIDE — the flagship thesis

Player development, proven weekly. Built for Storm Basketball (Belleville, IL) — October 2026.

This repo is a working thesis, not a finished company. Brand, pricing, and copy are
recommendations for Keith to revise, test, and own.

## The synthesis

Five web properties, five different approaches. This site is the winner's build:

- **Chassis — mybballplayer.com's operating system.** Evaluate → Focus → Train → Review in 6-week cycles. Labor-honest tiers (Foundation / Coached / Elite) so heavy-touch coaching is what the premium price buys. Weekly family recap.
- **Transplant — baller-connection's transfer thesis.** "Effort isn't the problem. Transfer is." The one-minute game log (did the focus show up? confidence 1–5) plus a confidence timeline. The only mechanism in the set that measures games instead of the driveway.
- **Framing — PROOF's evidence promise.** The parent report, the "proven weekly" claim, bandwidth feedback (1–2 key corrections, not every rep).
- **Brand — Baller Path house, Proof engine inside.** Kid-facing sells belonging ("I'm on the Baller Path"); parent-facing sells evidence ("your path, proven weekly").

Killed on mechanism grounds: ballerpath.com's video-free reflection-only loop (weakest verifiable proof — the parent never sees the work) and Storm Connect as a separate property (same loop + record; merged, not kept).

Oct 15 revision — the proof ladder: transfer reframed from "games or nothing" into three rungs (work → skill → transfer) so players without game minutes are fully included; the game log widened to a "compete log" (games, pickup runs, open gym, 1v1 — wherever there's a defender); the 6-week re-test promoted to the primary proof surface for non-starters.

## The accountability engine (10 mechanisms)

1. Weekly deadlines — rhythm is accountability
2. Specific-evidence check-ins — structured prompts, never a lone "done" button
3. Spot-check clips — random, constrained; honest without reviewing everything
4. Grace-day streaks — honesty stays cheaper than faking
5. The game log — did the focus survive contact?
6. Sunday parent summary — coach-approved, reads in a minute
7. 6-week re-test — ratings only move when it shows; the audit
8. Coach "needs you" list — nobody slips through
9. Pod streaks — team accountability, never individual leaderboards
10. The guarantee, reversed — miss a feedback window, that week is free

## Anti-fake design

- Speak-the-cue clips ("say the cue out loud") — proves attention
- Rotating evidence asks — unpredictability kills rehearsal
- Specificity prompts ("what broke down on rep 3?")
- Grace beats punishment — kids lie to unforgiving systems
- Parents as witnesses, not enforcers
- The re-test as ground truth
